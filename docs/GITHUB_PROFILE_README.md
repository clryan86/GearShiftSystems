## Featured project

### 🚗 [GearShift Systems](https://github.com/clryan86/GearShiftSystems)

A full-stack inventory, purchasing, and order-management system built with **Python, Flask, SQLAlchemy, SQLite, Bootstrap, Docker, and GitHub Actions**.

The application models an actual business workflow rather than a toy CRUD demo:

- inventory and vendor management
- SKU and reorder-threshold tracking
- session shopping cart
- order persistence
- purchase-order lifecycle management
- partial and complete inventory receiving
- stock-movement auditing
- CSV exports
- automated tests
- CI across multiple Python versions
- containerized deployment

**Engineering highlights:** application-factory architecture, relational domain modeling, historical order snapshots, environment-based configuration, automated workflow tests, GitHub Actions, and Docker/Gunicorn deployment.
